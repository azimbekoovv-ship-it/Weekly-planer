# Weekly Planner PWA

## Состав
- `index.html` — приложение (интерфейс, стили и логика в одном HTML)
- `manifest.webmanifest` — сведения для установки PWA
- `sw.js` — кеширование для офлайн-запуска и обновлений
- `icons/` — иконки приложения

## Установка на Android
PWA нельзя полноценно установить прямо из ZIP или локального HTML-файла. Её нужно разместить на HTTPS-хостинге.

1. Загрузите ВСЕ файлы и папку `icons` на один HTTPS-сайт (например, GitHub Pages, Netlify или ваш хостинг).
2. Откройте опубликованный HTTPS-адрес в Google Chrome на Android.
3. Нажмите появившуюся кнопку «Установить» или меню Chrome `⋮` → «Установить приложение» / «Добавить на главный экран».
4. Подтвердите установку. Иконка появится среди приложений и на главном экране.

После первого открытия приложение кешируется и сможет запускаться офлайн. Расписание и настройки хранятся локально в браузере этого устройства. Очистка данных сайта может удалить сохранённое расписание.

## Админ
PIN по умолчанию: `1234`. В режиме администратора нажмите и удерживайте строку режима администратора, чтобы открыть смену PIN. Данные не синхронизируются между разными телефонами.
